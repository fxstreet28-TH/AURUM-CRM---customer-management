# AURUM CRM — Recovered Project

This repository was recovered from the last working Vercel production deployment after the original GitHub repository became unavailable.

## Recovered pages

- Login
- Dashboard
- Customers
- Users
- Subscriptions
- MT5 connections
- Add/remove credit and credit log
- Activity log
- Permissions
- Settings

## Local preview

Run any static HTTP server from the repository root, for example:

```bash
npx serve .
```

Opening the HTML files directly with `file://` is not recommended because authentication and browser security behavior differ from a deployed site.

## Deployment

The project is a static HTML/CSS/JavaScript application and can be imported directly into Vercel. No build command is required.

## Recovery note

The pages and browser-side code match the last accessible production output. Git history and source files that were not included in the Vercel deployment could not be reconstructed from the public deployment.
